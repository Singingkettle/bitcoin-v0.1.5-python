# 第 0 章　学习路线图

> 这套教程的目标：让一个只有高中数学基础、会一点点 Python 的人，
> **彻底弄懂比特币是怎么工作的**——不是"大概知道"，而是能指着源码的每一行说出它为什么在那里。

## 0.1　这套教程是怎么设计的

比特币之所以难学，不是因为某一个知识点特别难，而是因为它把好几个领域的东西拧在了一起：
密码学、数据结构、计算机网络、概率论、博弈论、货币经济学。任何一本只讲其中一面的书，
读完都会让人觉得"好像懂了，又好像没懂"。

这里的办法是：**拿一份真实的、能运行的、足够小的比特币实现，从最底层的零件开始，一层一层往上搭。**

我们用的就是本仓库——中本聪 2009 年发布的 Bitcoin v0.1.5 的 Python 复刻版。选它有三个理由：

1. **它是源头。** 后来十几年的所有改进都建立在这 1 万多行 C++ 之上。
   理解了它，你就理解了比特币的"基因"；再去看今天的比特币，只是在看这个基因的演化。
2. **它足够小。** 今天的 Bitcoin Core 有几十万行代码，而 v0.1.5 的核心逻辑翻译成 Python 只有四千行左右（其中相当一部分还是中文注释），
   一个人完全可以逐行读完。
3. **它能跑。** 你读到的每一个概念，都可以立刻在自己电脑上运行、修改、搞破坏、看它怎么出错。

每一章都由四部分组成：

| 部分 | 作用 |
|---|---|
| **讲解** | 从生活中的类比和高中数学出发，把概念讲清楚 |
| **源码导读** | 指出这个概念落在哪个文件、哪个函数，关键的几行是什么意思 |
| **动手实验** | `labs/` 目录下的一个脚本，直接运行就能看到现象（每个脚本都被自动化测试保证能跑通） |
| **思考题** | 检验你是不是真的懂了（附答案） |

## 0.2　你需要的预备知识

* **数学**：高中水平就够。会用到的有：指数与对数、余数、概率（独立事件、期望）、一点点数列求和。
  椭圆曲线、有限域这些听起来吓人的东西，第 4 章会从"钟面上的算术"讲起。
* **编程**：能看懂简单的 Python（变量、函数、循环、类）。不需要会写复杂的程序——
  源码里的每个函数都有中文注释，教程会挑最关键的几行逐行解释。
* **英语**：源码里的变量名、函数名保持了英文（这样才能和中本聪的 C++ 原版对照），
  但都是简单的词，教程里第一次出现时会给出中文意思。

## 0.5　建议的学习节奏

不用急。下面是一个每天 1~2 小时的参考进度，总共约四周：

| 周 | 内容 | 这一周结束时你应该能…… |
|---|---|---|
| 第 1 周 | 第 1~5 章 | 手算一个区块头的哈希；解释公钥、私钥、地址的关系；说出为什么私钥不能从公钥反推 |
| 第 2 周 | 第 6~8 章 | 逐字节读懂一笔真实交易；在纸上模拟 P2PKH 脚本的执行；画出 5 笔交易的默克尔树 |
| 第 3 周 | 第 9~12 章 | 解释难度调整；说清楚一次链重组里发生了什么；解释"找零"和"余额"是怎么回事 |
| 第 4 周 | 第 13~16 章 | 画出两个节点同步区块的消息时序图；向朋友讲清楚比特币为什么不需要银行 |

每一章的推荐学法：

1. **先运行这一章的实验**，看输出，有个感性认识（不懂没关系）；
2. **读讲解部分**；
3. **打开对应的源文件**，对照"源码导读"把关键函数读一遍——源码里的中文注释是教程的延伸；
4. **回头再跑一遍实验**，这次你应该能解释每一行输出；
5. **改一改实验脚本**：把某个数字改掉、把某个字节弄坏，预测会发生什么，然后验证；
6. 做思考题。

## 0.6　源码地图

项目的核心在 `bitcoin/` 目录，一共 17 个文件，它们之间的依赖关系是一层压一层的：

```text
   第 14 章   node.py          把下面所有东西装配成一个节点；处理网络消息
   第 13 章   net.py           TCP 连接、消息的打包与拆包
              ─────────────────────────────────────────────
   第 12 章   wallet.py        钱包：哪些钱是我的、怎么花
   第 9 章    miner.py         矿工：打包交易、寻找 nonce
              ─────────────────────────────────────────────
   第 10 章   blockchain.py    共识核心：验证区块、选择最长链、重组
   第 11 章   mempool.py       内存池：还没进区块的交易
   第 10 章   db.py            存储：区块文件、索引数据库、钱包数据库
              ─────────────────────────────────────────────
   第 7 章    script.py        脚本虚拟机、签名的生成与验证
   第 8 章    block.py         区块、默克尔树、区块定位器
   第 6 章    tx.py            交易、输入、输出
              ─────────────────────────────────────────────
   第 5 章    base58.py        地址编码
   第 4 章    key.py           密钥、签名（封装 ecdsa 库）
   第 3 章    hashes.py  ripemd160.py     哈希函数
   第 2 章    serialize.py     把数据变成字节、把字节变回数据
              ─────────────────────────────────────────────
   贯穿全书   params.py        所有的常量（2100 万、10 分钟、2016 个块……都在这里）
              util.py  config.py          杂项工具、命令行参数
```

**上层依赖下层，下层不知道上层的存在。** 所以我们从最下面开始学。

一个有用的事实：这 17 个文件和中本聪原版的 C++ 文件是一一对应的（见[附录 B](appendix-b-fidelity.md)）。
学到后面如果你想挑战一下，可以直接去读[原版源码](https://github.com/bitcoin/bitcoin/tree/v0.1.5)——
你会发现函数名、变量名、甚至注释都似曾相识。

## 0.7　关于"忠实复刻"的一个提醒

这份代码复刻的是 **2009 年** 的比特币，它和今天的比特币在细节上有不少差别，
还原样保留了几个后来被修复的著名漏洞（教程会一一指出）。这是有意为之：

* 看到漏洞，你才会明白后来的那些修复为什么是必要的；
* 看到最初的、朴素的设计，你才能看清比特币的骨架，而不被十几年积累的工程细节淹没。

第 16 章会专门梳理从 0.1.5 到今天的主要变化。
